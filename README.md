# Install UFW:
 sudo apt install -y ufw

# Basic Commands
 sudo ufw allow ssh
 sudo ufw deny http
 sudo ufw enable

# Check Detailed Status
 sudo ufw status verbose

# Important Notes
 Always allow SSH before enabling UFW to avoid getting locked out.
 Use firewall rules responsibly.
 Do not block essential services.

# Conclusion
 This project provides a basic understanding of configuring a firewall using UFW. It is useful for beginners in cybersecurity and system administration.
